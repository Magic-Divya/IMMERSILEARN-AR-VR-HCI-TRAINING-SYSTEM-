PROJECT OVERVIEW

About ImmersiLearn

An AR/VR HCI training system concept that combines immersive exploration with active learning.

◎

Project vision

ImmersiLearn demonstrates how immersive technologies can support experiential learning through interactive environments, guided activities and immediate feedback.

⌘

HCI focus

The interface applies visibility, feedback, consistency, affordances, user control, accessibility and error prevention to make interactions understandable.

⬡

Technology

Built with semantic HTML, modern CSS and vanilla JavaScript. Progress is stored locally in the browser using localStorage. No backend or installation is required.

Learning design principles

01 · Discoverability

Make possible actions visible and easy to find.

02 · Feedback

Show the result of every meaningful action.

03 · User control

Allow users to pause, reset and navigate freely.

04 · Accessibility

Use readable contrast, clear labels and keyboard support.

05 · Consistency

Reuse patterns so users can transfer what they learn.

06 · Error prevention

Provide guidance before users make avoidable mistakes.
